# Friday Ledger (starter)

A weekly budget planner that opens blank, in any currency. You add how you get paid (weekly, every few weeks, monthly or last working day), then your bills, loans, debts and savings goals. It plans every week, shows what is left, and gives a monthly review.

All data stays on the device it is used on. Use Setup, then Download backup, to keep a copy.

## Build the Android app
Push this folder to a GitHub repo. The Build APK action runs on its own. Open the run, download the artifact, unzip it and install `app-debug.apk` on an Android phone.

## Or just use it in a browser
Open `www/index.html` in any browser.
